## 登入與導覽

後台所有頁面皆需登入。未登入時將被導向登入頁面。

登入後，左側邊欄依功能分為三組：

| 分組 | 頁面 |
|------|------|
| **總覽** | 儀表板、管線狀態、數據分析 |
| **內容** | 文章管理、審稿佇列、素材庫 |
| **設定** | 寫手管理、球種分類、爬蟲來源、發布頻道、比分設定 |

- 當前所在頁面會以白色背景高亮顯示。
- 「審稿佇列」與「素材庫」右側會顯示待處理數量，每 60 秒自動更新。
- 手機版側邊欄預設隱藏，點擊左上角漢堡選單可展開。
- 側邊欄底部可登出。

## 儀表板

**路徑**：後台首頁

儀表板提供平台營運的即時概覽，分為「統計卡片」與「爬蟲狀態」兩個區塊。

### 統計卡片

頁面上方以 8 張卡片呈現關鍵數據：

| 卡片 | 說明 |
|------|------|
| 原始新聞總數 | 資料庫中所有已爬取的原始新聞數量 |
| 今日爬取 | 今天新爬取的原始新聞數量 |
| 今日產出 | 今天由 AI 產出的文章數量 |
| 未發布 | 產出後尚未發布的文章數量 |
| 已發布 | 已發布到前台的文章總數 |
| 今日發布 | 今天發布的文章數量 |
| 排程中 | 已排程但尚未到發布時間的文章數量 |
| 總瀏覽數 | 所有已發布文章的累計瀏覽次數 |

### 爬蟲狀態

卡片下方的表格顯示每個爬蟲來源的健康狀況：

| 欄位 | 說明 |
|------|------|
| 來源 | 爬蟲來源名稱 |
| 文章數 | 該來源已爬取的文章總數 |
| 最後爬取 | 距離上次成功爬取的時間（如「3 小時前」） |
| 狀態燈號 | 健康度指示燈 |

**狀態燈號判讀**：

- **綠燈**（正常）：24 小時內有成功爬取
- **黃燈**（注意）：24 至 48 小時內未爬取，建議檢查來源是否正常
- **紅燈**（異常）：超過 48 小時未爬取，需立即排查原因

## 球種分類

**路徑**：設定 > 球種分類

管理平台支援的運動項目（籃球、棒球、美式足球、足球），控制哪些球種納入爬取與產文流程。

### 球種卡片

每個球種以獨立卡片呈現，包含：

- **球種名稱**與相關關鍵字
- **啟用/停用開關**（Switch）
- **啟用狀態標籤**（已啟用/未啟用）
- **爬蟲來源勾選區**（僅啟用時顯示）

### 操作說明

#### 啟用或停用球種

1. 找到目標球種卡片。
2. 切換右上角的開關。
3. 開關切換後立即生效，無需額外儲存。

**影響範圍**：停用後，該球種的新聞將不再被爬取，AI 也不會為該球種產文。

#### 設定球種的爬蟲來源

1. 確認球種處於「已啟用」狀態（停用時不會顯示來源選項）。
2. 在卡片下方的來源清單中，勾選或取消勾選來源。
3. 勾選狀態即時儲存。

設定後，該球種僅會從已勾選的來源爬取新聞。

> **注意**：球種清單由系統定義，目前無法從後台新增新球種。

## 爬蟲來源

**路徑**：設定 > 爬蟲來源

管理新聞爬蟲的來源網站，支援新增、編輯、刪除、手動爬取等操作。

### 來源列表

每個來源顯示以下資訊：

| 欄位 | 說明 |
|------|------|
| 名稱 | 來源的識別名稱 |
| URL | 來源網站的基礎網址 |
| 圖片爬取 | 是否同時下載文章內的圖片（開關控制） |
| 操作 | 編輯、刪除、手動爬取 |

### 操作說明

#### 新增來源

1. 在頁面底部的新增區域填入「來源名稱」與「Base URL」。
2. 兩個欄位皆為必填。
3. 點擊「新增」按鈕。

#### 編輯來源

1. 點擊來源右側的「編輯」按鈕。
2. 修改名稱或 URL。
3. 點擊「儲存」。

> **注意**：修改名稱時，系統會自動同步更新所有球種中對該來源的引用，無需手動調整。

#### 刪除來源

1. 點擊來源右側的「刪除」按鈕。
2. 在確認對話框中點擊「刪除」。

> **注意**：刪除為永久操作，無法復原。刪除後，該來源會自動從所有球種的來源清單中移除。

#### 手動觸發爬取

1. 點擊來源右側的「爬取」按鈕。
2. 等待爬蟲執行完成。
3. 完成後會顯示爬取結果：
   - **total**：本次爬取的文章總數
   - **saved**：成功儲存的新文章數
   - **duplicate**：已存在的重複文章數
   - **filtered**：被過濾的文章數

#### 切換圖片爬取

- 切換來源的「圖片爬取」開關，控制該來源是否下載文章圖片。
- 即時生效。

## 發布頻道

**路徑**：設定 > 發布頻道

管理文章發布到社群平台的頻道設定，支援 Telegram、Line、Facebook、Twitter。

### 頻道卡片

每個頻道以卡片呈現，包含頻道名稱、類型、啟用開關。

### 操作說明

#### 新增頻道

1. 在頁面上方的表單中選擇頻道類型（Telegram / Line / Facebook / Twitter）。
2. 填入頻道名稱。
3. 根據所選類型，填入對應的設定參數（如 Telegram 需填 Bot Token 和 Chat ID）。
4. 點擊「新增」按鈕。

新增的頻道預設為啟用狀態。

#### 編輯頻道

1. 點擊頻道卡片上的「編輯」按鈕。
2. 修改名稱、類型或設定參數。
3. 點擊「儲存」。

> **注意**：切換頻道類型時，設定參數會重置為該類型的預設模板。

#### 啟用/停用頻道

- 切換頻道卡片上的開關，即時生效。
- 停用的頻道在文章發布時不會收到推送。

#### 刪除頻道

1. 點擊「刪除」按鈕。
2. 在確認對話框中確認刪除。

刪除為永久操作，無法復原。

## 即時比分設定

**路徑**：設定 > 比分設定

管理前台「即時比分」頁面顯示的聯賽資料來源。每筆設定對應一個 ESPN 資料端點。

### 設定表格

| 欄位 | 說明 |
|------|------|
| 排序 | 數字越小越靠前，控制前台的聯賽顯示順序 |
| 聯賽 | 聯賽顯示名稱（如 NBA、MLB） |
| ESPN Endpoint | ESPN API 路徑（如 `basketball/nba`） |
| 球種 | 該聯賽所屬的運動項目 |
| 啟用 | 開關控制是否在前台顯示 |
| 操作 | 編輯、刪除 |

### 操作說明

#### 新增比分來源

1. 點擊右上角「+ 新增比分來源」按鈕。
2. 在彈出的對話框中填寫：
   - **球種 Key**：運動項目識別碼（如 `basketball`、`baseball`、`soccer`）
   - **聯賽 Key**：聯賽唯一識別碼（如 `nba`、`mlb`、`epl`），建立後不可修改
   - **顯示名稱**：前台顯示的聯賽名稱
   - **ESPN Endpoint**：ESPN API 的路徑（如 `basketball/nba`）
   - **排序**：數字越小排越前面，預設為 0
3. 點擊「儲存」或按 Enter 送出。

新增的比分來源預設為停用狀態，需手動啟用。

#### 編輯比分來源

1. 點擊該筆資料的「編輯」按鈕。
2. 修改需要變更的欄位（聯賽 Key 不可修改）。
3. 點擊「儲存」或按 Enter 送出。

#### 啟用/停用

- 切換「啟用」欄的開關，即時生效。
- 僅啟用的聯賽會顯示在前台即時比分頁面。

#### 刪除

1. 點擊「刪除」按鈕。
2. 在確認對話框中確認。

刪除為永久操作，無法復原。

## 寫手管理

**路徑**：設定 > 寫手管理

管理 AI 寫手的人設（Persona），控制 AI 產文時的風格、專長與產量。

### 寫手卡片

每個寫手以卡片呈現，包含名稱、描述、寫手類型、專長標籤、啟用開關。

### 操作說明

#### 新增寫手

1. 點擊右上角「新增寫手」按鈕。
2. 頁面頂部會出現表單，填寫以下欄位：
   - **名稱**（必填）：寫手的顯示名稱
   - **描述**：簡短介紹寫手特色
   - **風格提示詞**（必填）：給 AI 的寫作風格指引
   - **寫手類型**：columnist（專欄作家）或 reporter（記者），預設為 columnist
   - **專長設定**：包含球種、聯賽、隊伍三個維度
   - **每批次最大文章數**：預設為 2
   - **頭像 URL**：寫手的頭像圖片網址
   - **專長標籤**：以逗號分隔的標籤文字
3. 點擊「儲存」。

#### 編輯寫手

1. 點擊寫手卡片上的「編輯」按鈕。
2. 頁面會自動捲動至頂部顯示編輯表單。
3. 修改後點擊「儲存」。

#### 啟用/停用寫手

- 切換寫手卡片上的開關，即時生效。
- 停用的寫手不會被 AI 管線選用產文。

#### 刪除寫手

1. 點擊「刪除」按鈕。
2. 在確認對話框中確認。

刪除為永久操作，無法復原。

### 系統寫作規則

寫手列表下方有「系統寫作規則」區塊，用於設定全域適用的寫作規範。這些規則會套用到所有寫手的產文流程中。

## 數據分析

**路徑**：總覽 > 數據分析

數據分析頁面分為「訪客分析」和「內容成效」兩個分頁，可透過頁面右上角的切換按鈕切換。

### 訪客分析

顯示網站流量與訪客行為數據，支援 7 天 / 30 天 / 90 天三種時間範圍。

#### 摘要卡片（6 張）

| 卡片 | 說明 |
|------|------|
| 今日 PV | 今天的頁面瀏覽次數（Page View） |
| 今日 UV | 今天的不重複訪客數（Unique Visitor） |
| 總 PV | 選定時間範圍內的總頁面瀏覽次數 |
| 總 UV | 選定時間範圍內的不重複訪客數 |
| 頁/人 | 平均每位訪客瀏覽的頁面數 |
| 會員瀏覽 | 已登入會員的瀏覽次數 |

#### 每日 PV/UV 趨勢

以橫條圖呈現每日的 PV 和 UV 數據，方便觀察流量波動。

#### 熱門頁面 TOP 20

列出瀏覽量最高的 20 個頁面，顯示頁面名稱、PV 和 UV。

#### 流量來源

顯示訪客的來源分佈（如直接訪問、搜尋引擎、社群平台等），以百分比長條圖呈現。

#### 裝置分佈

顯示 Desktop（桌面）、Mobile（手機）、Tablet（平板）三種裝置的訪客佔比。

#### 最近訪客

以 session 為單位列出最近的訪客記錄：

- 顯示 Session ID、瀏覽頁數、最後瀏覽頁面、訪問時間。
- 已登入會員的 Session ID 會以紫色標示。
- 點擊可展開查看該訪客的完整瀏覽軌跡（依時間排列的頁面造訪記錄）。

#### 切換時間範圍

在頁面右上角選擇「7 天」、「30 天」或「90 天」，資料會即時重新載入。

### 內容成效

顯示文章發布後的表現數據。

#### 摘要卡片（4 張）

| 卡片 | 說明 |
|------|------|
| 總瀏覽次數 | 所有已發布文章的累計瀏覽次數 |
| 已發布文章 | 目前已發布的文章總數 |
| 平均瀏覽數 | 每篇文章的平均瀏覽次數 |
| 平均文章長度 | 所有已發布文章的平均字數 |

#### 每日文章瀏覽趨勢（近 30 天）

以直條圖呈現每日的文章瀏覽量。

#### 熱門文章 TOP 10

列出瀏覽次數最高的 10 篇文章，顯示標題、分類、瀏覽次數。點擊標題可跳轉至文章管理頁面。

#### 分類瀏覽統計

以長條圖呈現各分類的瀏覽量與文章數，按瀏覽量由高到低排列。

## 常見問題（FAQ）

### 修改設定後需要重新部署嗎？

不需要。所有後台設定變更即時生效，不需要重新部署或重啟服務。

### 開關類操作需要按「儲存」嗎？

不需要。所有 Switch（開關）操作都是即時生效的，切換後系統會自動儲存並顯示操作結果通知。

### 刪除操作可以復原嗎？

不可以。爬蟲來源、發布頻道、比分設定、寫手的刪除皆為永久刪除。系統會在刪除前彈出確認對話框，請在確認前仔細核對。

### 為什麼看不到球種的爬蟲來源選項？

球種必須處於「已啟用」狀態才會顯示爬蟲來源勾選區域。請先啟用該球種。

### 為什麼新增的比分來源在前台看不到？

新增的比分來源預設為「停用」狀態。請在比分設定表格中將該來源的啟用開關打開。

### 刪除爬蟲來源後，球種設定會受影響嗎？

會。刪除爬蟲來源時，系統會自動將該來源從所有球種的來源清單中移除，無需手動處理。

### 可以從後台新增新的球種嗎？

目前不行。球種清單（籃球、棒球、美式足球、足球）由系統定義，新增球種需透過工程團隊修改程式碼。

### 數據分析的資料多久更新一次？

數據分析頁面的資料在每次進入頁面或切換分頁/時間範圍時即時查詢。訪客分析的時間範圍可選 7 天、30 天或 90 天。

### 儀表板的爬蟲狀態多久刷新？

爬蟲狀態資料每 5 分鐘自動更新一次。若需要查看最新狀態，重新整理頁面即可。

### 如何判斷爬蟲是否出問題？

查看儀表板的爬蟲狀態表格。若某個來源的狀態燈號為黃燈或紅燈，表示該來源在一段時間內未成功爬取，建議：

1. 確認該來源網站是否正常運作。
2. 前往「爬蟲來源」頁面，嘗試手動觸發爬取。
3. 若手動爬取也失敗，可能是來源網站結構變更，需通知工程團隊處理。
