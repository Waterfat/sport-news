## 1. 進入文章管理

登入後台後，從左側導覽列點選「文章管理」，即可進入文章列表頁。

頁面頂部會顯示目前的文章總數，以及每頁顯示篇數的選擇器（預設每頁 20 篇）。

---

## 2. 文章列表

文章列表以表格形式呈現（手機版為卡片式排版），每篇文章顯示以下資訊：

| 欄位 | 說明 |
|------|------|
| 勾選框 | 用於批次操作的選取框 |
| 縮圖 | 文章的第一張圖片預覽 |
| 標題 | 文章標題，旁邊的數字徽章代表參考素材數量 |
| 分類 | 運動分類（如 NBA、MLB、NPB 等），以色標區分 |
| 寫手 | AI 寫手名稱 |
| 瀏覽 | 已發布文章的瀏覽次數（未發布文章顯示「-」） |
| 狀態 | 未發布 / 排程中 / 已發布 |
| 建立時間 | 文章由 AI 產出的時間；若已排程，會額外顯示預定發布時間 |
| 操作 | 發布、排程、查看等按鈕 |

### 分頁瀏覽

- 頁面底部提供分頁導覽，可點選頁碼或使用「上一頁 / 下一頁」按鈕切換。
- 右上角可調整每頁顯示篇數。
- 支援直接輸入頁碼跳轉。

## 3. 篩選與排序

### 狀態篩選

文章列表上方有四個 Tab 標籤，點擊即可切換顯示：

- **全部** -- 顯示所有文章
- **未發布** -- 僅顯示尚未發布、也未排程的文章
- **排程中** -- 僅顯示已設定預約發布時間的文章
- **已發布** -- 僅顯示已經上線的文章

### 分類篩選

在狀態 Tab 旁邊有分類下拉選單，可選擇特定運動分類（如 NBA、MLB、NPB 等）來過濾文章。選擇「所有分類」可取消分類篩選。

### 書籤與分享

所有篩選條件會自動同步到瀏覽器網址列。你可以將當前的篩選結果加入書籤，或將網址分享給同事，對方開啟後會看到相同的篩選結果。

## 4. 單篇發布

在文章列表的操作欄中，未發布的文章會顯示「發布」按鈕。

**操作步驟：**

1. 找到要發布的文章，點擊該列右側的「發布」按鈕。
2. 系統會立即將文章發布到所有已啟用的社群頻道。
3. 發布過程中按鈕會顯示旋轉動畫及「發布中」文字，請稍候。
4. 發布完成後，文章狀態會自動更新為「已發布」。

> 注意：文章必須通過 AI 審查且包含圖片，才能成功發布。若發布失敗，畫面右下角會顯示錯誤提示。

## 5. 排程發布（預約發布）

排程發布可讓你設定一個未來的時間，系統會在該時間自動發布文章。

### 從列表頁設定排程

1. 找到要排程的未發布文章，點擊「排程」按鈕。
2. 彈出日期時間選擇器，選擇預定發布的日期和時間。
3. 點擊「確認排程」完成設定。
4. 文章狀態會變更為「排程中」，並在建立時間下方顯示排程時間。

### 從詳情頁設定排程

1. 進入文章詳情頁，找到「發布選項」區塊。
2. 可先勾選要發布的社群頻道（見下方「選擇發布頻道」說明）。
3. 在日期時間輸入欄選擇預定發布時間。
4. 點擊「排程發布」按鈕完成設定。

### 取消排程

若需要取消已排程的文章：

1. 進入該文章的詳情頁。
2. 在排程狀態卡片中，點擊「取消排程」按鈕。
3. 文章會回到「未發布」狀態，可重新排程或直接發布。

## 6. 批次操作

當需要一次處理多篇文章時，可使用批次操作功能。

### 選取文章

- **逐篇選取**：點擊每篇文章左側的勾選框。
- **全選**：點擊表格標題列的勾選框，選取當前頁面所有文章。
- **取消全選**：再次點擊標題列的勾選框，即可取消全部選取。

選取文章後，列表上方會出現批次操作列，顯示「已選取 N 篇」及可用的操作按鈕。

### 批次發布

1. 勾選要發布的多篇文章。
2. 點擊批次操作列中的「批次發布」按鈕。
3. 系統會彈出確認對話框，顯示即將發布的文章數量。
4. 點擊「發布」確認，或點擊「取消」放棄操作。
5. 確認後，系統會依序發布所有選取的文章。

### 批次刪除

1. 勾選要刪除的多篇文章。
2. 點擊批次操作列中的「批次刪除」按鈕。
3. 系統會彈出確認對話框。
4. 點擊「刪除」確認。

> 注意：批次刪除操作無法復原，請確認後再執行。

### 取消選取

點擊批次操作列中的「取消選取」按鈕，可清除所有已選取的文章。切換狀態 Tab 或分類時，選取也會自動清除。

## 7. 文章詳情與編輯

### 進入詳情頁

在文章列表中，點擊文章標題或右側的「查看」按鈕，即可進入文章詳情頁。

### 頁面結構

詳情頁包含以下區塊：

- **頂部導覽列** -- 返回按鈕、文章狀態標籤、寫手名稱、文章標籤、編輯按鈕
- **發布/排程狀態卡片** -- 顯示目前的發布狀態或排程時間
- **發布選項卡片** -- 僅未發布文章可見，提供頻道選擇與發布/排程功能
- **審稿與寫作資訊卡片** -- 顯示 AI 審稿結果
- **改寫文章卡片** -- 文章的完整標題、內文及附圖
- **參考來源卡片** -- AI 產文時參考的原始素材
- **引用來源卡片** -- 文章引用的外部連結

### 編輯文章

只有「未發布」狀態的文章可以編輯。

1. 點擊頂部的「編輯」按鈕，進入編輯模式。
2. **修改標題**：在標題輸入欄中直接修改文字。
3. **修改內文**：在內文編輯區中修改文章內容（支援純文字格式）。
4. 修改完成後，點擊「儲存修改」按鈕。
5. 若要放棄修改，點擊「取消」按鈕。

> 注意：編輯中若關閉瀏覽器或離開頁面，未儲存的修改會遺失。請記得在離開前儲存。

### 管理附圖

文章附圖顯示在內容區塊底部。

- **查看大圖**：點擊圖片可在新分頁中開啟原始大圖。
- **刪除圖片**：將滑鼠移到圖片上方，右上角會出現紅色刪除按鈕，點擊即可移除該圖片。

### 選擇發布頻道

在詳情頁的「發布選項」卡片中（僅未發布文章可見），可以選擇文章要發布到哪些社群頻道：

1. 預設會勾選所有已啟用的頻道。
2. 取消勾選不需要發布的頻道。
3. 設定好頻道後，點擊「直接發布」或「排程發布」。

目前支援的頻道包含 Telegram、LINE、Facebook、Twitter（依實際啟用狀況而定）。

### 從詳情頁發布

1. 在「發布選項」卡片中確認發布頻道。
2. 點擊「直接發布」按鈕，文章會立即發布。
3. 發布過程中按鈕會顯示「處理中...」，請稍候。

## 8. 審稿結果

每篇文章經 AI 管線產出後，會自動進行審稿。審稿結果顯示在詳情頁的「審稿與寫作資訊」卡片中。

### 審稿資訊說明

| 項目 | 說明 |
|------|------|
| 寫作策略 | AI 採用的寫作方式，分為「多源綜合」、「內容增值」、「熱門綜合」三種 |
| 審稿狀態 | 待審（黃色）、通過（綠色）、未通過（紅色） |
| 審查時間 | AI 完成審稿的時間 |

### 評分明細

審稿結果包含 9 項評分，每項分數以顏色區分：

- **綠色** -- 分數 7 分以上，品質良好
- **無特殊顏色** -- 分數 4-6 分，品質普通
- **紅色** -- 分數低於 4 分，品質待改善

卡片底部會顯示所有項目的平均分數。

### 通過/不通過項目

除了評分外，還有 Pass/Fail 的檢查項目（如題材去重、是否有圖片等）。每個項目會以綠色（Pass）或紅色（Fail）標籤顯示。

### 審查意見

若 AI 審稿有額外建議或說明，會以文字區塊顯示在評分下方。

### 如何處理未通過的文章

1. 查看審稿評分和意見，了解需要改進的地方。
2. 點擊「編輯」按鈕，修改文章標題或內文。
3. 儲存修改後，可依實際品質判斷是否仍要發布。

## 9. 查看原始素材與引用來源

### 參考來源（原始素材）

「參考來源」卡片列出 AI 產文時參考的所有原始新聞素材，每則素材包含：

- **來源標籤** -- 素材的來源網站
- **原始連結** -- 點擊可前往原始新聞頁面
- **標題** -- 原始新聞的標題
- **內容摘要** -- 原始新聞的前 500 字內容

這些資訊可用於查證文章內容的正確性。

### 引用來源

「引用來源」卡片列出文章中引用的外部連結，每則包含：

- **來源類型** -- 分為「原始文章」、「網路搜尋」、「社群媒體」
- **標題** -- 引用內容的標題
- **連結** -- 點擊可前往原始頁面

## 10. 管線規劃與產出

文章列表頁頂部有「產出控制面板」，可用來觸發 AI 管線產出新文章。

### 觸發規劃

1. 點擊控制面板中的「規劃」按鈕。
2. 按鈕會變為「規劃中...」，並出現「規劃產生中」的動態提示。
3. 等待 AI 完成規劃後，下方會出現規劃列表。

### 管理規劃項目

規劃列表顯示 AI 建議的文章題材，你可以：

- **勾選/取消勾選** -- 選擇要實際產出的規劃項目。
- **刪除** -- 移除不需要的規劃項目（會彈出確認對話框）。
- **產出** -- 點擊「產出」按鈕，AI 會根據選取的規劃項目開始撰寫文章。

### 產出狀態

- 控制面板右側會顯示最後一次執行的時間。
- 產出過程中，面板會顯示「文章產出中」的動態提示。
- 產出完成後，新文章會自動出現在文章列表中。

## 11. 故障排除

### 點擊「發布」後出現錯誤提示

**可能原因與解決方式：**

- **文章未通過審查** -- 進入詳情頁查看審稿狀態，確認為「通過」後再發布。
- **文章沒有圖片** -- 系統要求文章至少有一張圖片才能發布。若圖片被誤刪，目前需由管理員從資料庫恢復。
- **社群頻道 API 異常** -- 可能是某個發布頻道暫時無法連線。請稍後重試，或在詳情頁取消勾選有問題的頻道後再發布。

### 文章列表載入緩慢或無法載入

- 檢查網路連線是否正常。
- 嘗試重新整理頁面。
- 減少每頁顯示篇數（例如從 100 調整為 20）。
- 若問題持續，請聯繫技術人員確認後端服務狀態。

### 編輯後儲存失敗

- 檢查網路連線。
- 確認文章狀態仍為「未發布」（已發布的文章無法編輯）。
- 嘗試重新整理頁面後再次編輯。
- 建議先複製修改內容到剪貼簿，避免重新整理後遺失。

### 排程發布未在預定時間執行

- 確認排程時間是否正確（注意時區為台灣時間）。
- 確認文章狀態顯示為「排程中」且排程時間正確。
- 若排程時間已過但文章仍未發布，請聯繫技術人員檢查排程服務是否正常運行。

### 批次操作部分失敗

- 畫面會顯示錯誤提示，說明失敗原因。
- 檢查失敗的文章是否符合發布條件（審查通過、有圖片）。
- 可針對失敗的文章個別處理後重試。

### 規劃或產出功能無回應

- 「規劃」或「產出」按鈕在執行中會自動停用，請耐心等待。
- 若等待超過五分鐘仍無回應，請重新整理頁面。
- 若問題持續，請聯繫技術人員確認管線服務是否正常運行。
