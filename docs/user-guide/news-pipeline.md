# 新聞管線使用指南

本指南面向內容營運者，說明如何操作 Howger Sport 的自動化新聞管線系統。

---

## 概述

新聞管線是一套自動化內容生產系統，流程如下：

```
爬取新聞素材 → AI 規劃文章 → AI 產出文章 → AI 審稿 → 多渠道發布
```

大部分流程自動運作，營運者只需：
- 管理爬蟲來源和寫手設定
- 監控管線運作狀態
- 偶爾手動審核或觸發管線

---

## 1. 管線監控（Pipeline 頁面）

**路徑**：後台 → Pipeline

### 管線階段

頁面顯示管線 5 個階段的即時數量：

| 階段 | 說明 |
|------|------|
| 爬蟲素材 | 已爬取但尚未被 AI 處理的原始文章數 |
| 待規劃 | 等待 AI 分析並規劃成文章方案 |
| 產文中 | AI 正在根據規劃方案撰寫文章 |
| 待審稿 | AI 產出的草稿等待審核 |
| 已發布 | 審核通過並已發布的文章 |

### 自動化設定

在 Pipeline 頁面下方可以設定自動化行為：

- **自動模式開關**：啟用後，系統會自動在素材累積到門檻時觸發整條管線
- **累積門檻**：設定多少篇未處理素材時自動開始（預設由系統設定，範圍 1-50 篇）
- **檢查間隔**：多久檢查一次素材數量（範圍 1-1440 分鐘）

頁面也會顯示：
- 目前待處理素材數，以及是否已達門檻
- 上次自動執行的時間和結果
- 錯誤訊息（如果上次執行失敗）

## 2. 爬蟲來源管理（Sources 頁面）

**路徑**：後台 → Sources

### 新增來源

1. 在頁面上方輸入「來源名稱」和「來源網址」
2. 點擊「新增」

### 編輯來源

1. 點擊來源右側的編輯按鈕
2. 修改名稱或網址
3. 點擊「儲存」或「取消」

### 刪除來源

1. 點擊刪除按鈕
2. 確認對話框中點擊確認
3. 來源會同時從所有運動項目的來源清單中移除

### 爬取圖像設定

每個來源有「爬取圖像」開關，啟用後爬蟲會同時下載文章中的圖片。

### 手動觸發爬取

點擊來源旁的「爬蟲」按鈕，立即對該來源執行一次爬取。完成後會顯示結果：
- **總數**：找到的文章數
- **保存**：成功儲存的新文章數
- **重複**：已存在的文章數（跳過）
- **過濾**：被球種設定過濾的文章數

## 3. AI 管線操作

### 自動模式

開啟自動模式後，管線會自動完成以下流程：

1. **規劃**：AI 讀取最近 12 小時的新素材，分析去重，產出規劃方案
2. **產文**：規劃完成後自動接力，AI 根據寫手風格產出文章
3. **審稿**：產文完成後自動接力，AI 進行 9 項品質審查
4. **發布**：審查通過的文章自動發布到所有啟用的渠道

### 手動觸發

如果需要手動觸發管線（例如自動模式關閉時），可以在 Pipeline 頁面操作。

### 查看原始素材

**路徑**：後台 → Raw

可以瀏覽所有已爬取的原始文章：
- 按來源篩選（全部 / ESPN / Yahoo / ETtoday）
- 查看每篇素材的處理狀態（已處理 / 未處理）
- 點擊標題可開啟原始文章連結

### 審核 AI 產出

**路徑**：後台 → Review

此頁面有兩個標籤：

**待審稿**：
- 顯示所有等待人工審核的 AI 草稿
- 點擊「核准」→ 文章進入發布佇列
- 點擊「退回」→ 輸入退回理由（選填）→ 文章被標記為退回

**審稿歷史**：
- 查看所有已核准和已退回的文章記錄

> 注意：自動模式下，AI 審稿通過的文章會自動發布，不需要人工審核。Review 頁面主要用於手動審核流程或查看歷史。

## 4. 寫手人設管理（Personas 頁面）

**路徑**：後台 → Personas

### 新增寫手

1. 點擊「新增寫手」
2. 填寫以下資訊：

| 欄位 | 說明 | 必填 |
|------|------|------|
| 名稱 | 寫手名稱 | 是 |
| 描述 | 寫手簡介 | 否 |
| 風格提示詞 | AI 產文時的風格指令（如「專業嚴謹、引用數據」） | 是 |
| 寫手類型 | `columnist`（專欄作家）/ `general`（一般）/ `specialist`（專家） | 是 |
| 專長 — 球種 | 擅長的運動（籃球、棒球、足球等） | 否 |
| 專長 — 聯盟 | 擅長的聯盟（NBA、MLB、英超等） | 否 |
| 專長 — 球隊 | 擅長的球隊 | 否 |
| 最大文章數 | 每次產文的上限篇數（預設 2） | 否 |

3. 點擊「儲存」

### 專長匹配規則

- 沒有設定任何專長的寫手 = 全能寫手，會收到所有文章
- 設定了專長後，AI 只會分配符合該寫手專長的素材
- 系統會根據文章內容的關鍵字出現頻率，判斷文章的主分類
- 建議至少保留一位全能寫手，避免有素材無人處理

### 啟用/停用寫手

- 點擊寫手卡片上的開關可以啟用或停用
- 停用的寫手不會被分配任何素材

## 5. 發布渠道管理（Channels 頁面）

**路徑**：後台 → Channels

### 新增渠道

1. 輸入渠道名稱
2. 選擇渠道類型
3. 填入對應的憑證

| 渠道類型 | 需要的憑證 |
|---------|-----------|
| Telegram | Bot Token、Chat ID |
| Facebook | Page ID、Access Token |
| X/Twitter | API Key、API Secret、Access Token、Access Token Secret |
| LINE | Channel Access Token |

4. 點擊「新增」

### 啟用/停用渠道

- 點擊渠道卡片的開關
- 停用的渠道不會收到文章推播
- 停用不會刪除設定，重新啟用即可恢復

### 安全性

- 渠道憑證在頁面上以掩碼顯示（只看到前 3 碼和後 3 碼）
- 編輯時可以看到完整憑證

---

## 6. 文章管理（Articles 頁面）

**路徑**：後台 → Articles

管理所有 AI 產出的文章（包含已發布和草稿）。

- 查看文章狀態（已發布 / 草稿 / 退回）
- 點擊文章進入編輯頁面
- 在編輯頁面可以：修改標題和內容、查看引用的原始素材、手動設定發布渠道和時間、查看審核結果

## 7. 故障排除

### 管線沒有自動觸發

**可能原因**：
1. 自動模式未開啟 → 到 Pipeline 頁面開啟自動模式
2. 素材未達門檻 → 檢查目前待處理素材數和設定的門檻
3. Listener 服務停止 → 需要技術人員檢查 Mac Mini 上的 listener 程序

### 爬蟲沒有新素材

**可能原因**：
1. 來源網站改版 → 手動觸發爬取確認是否有錯誤
2. 所有來源都已停用 → 到 Sources 頁面確認有啟用的來源
3. 球種設定過濾了所有文章 → 到 Sports 頁面確認有啟用的球種

### AI 產出的文章品質不佳

**改善方式**：
1. 調整寫手的「風格提示詞」，給予更具體的寫作指引
2. 確保專長設定正確，避免寫手收到不擅長的素材
3. 調整「最大文章數」，減少單次產出量以提升品質

### 文章發布失敗

**可能原因**：
1. 渠道憑證過期或無效 → 到 Channels 頁面更新憑證
2. 社群平台 API 限制 → 稍後重試
3. 文章無圖片 → 系統要求文章至少有一張圖片才能發布

### 出現重複文章

系統有多層去重機制，但如果仍然出現重複：
- AI 規劃階段會比對近 14 天已發布文章的標題
- AI 審稿階段會檢查題材和圖片是否重複
- 如果去重失效，可能是素材標題差異過大但內容相同，可以在 Review 頁面手動退回

## 常見問題

### Q：管線多久執行一次？
A：取決於自動化設定的「檢查間隔」。系統每隔設定的時間檢查一次素材數量，達到門檻就自動觸發。爬蟲的觸發頻率則取決於 Vercel Cron 的排程設定。

### Q：AI 產出的文章可以手動修改嗎？
A：可以。在 Articles 頁面點擊文章進入編輯頁面，可以修改標題、內容、圖片等。修改後的文章可以手動發布。

### Q：一篇文章可以只發到特定渠道嗎？
A：可以。在文章編輯頁面的「發布選項」中，可以選擇要發布到哪些渠道。不選擇時預設發到所有啟用的渠道。

### Q：如何暫停整條管線？
A：到 Pipeline 頁面關閉「自動模式」即可。關閉後系統不會自動觸發任何階段，但手動觸發仍然可用。

### Q：寫手專長設定的「綜合」是什麼意思？
A：設定「綜合」球種的寫手等同於全能寫手，會收到所有類型的文章。
